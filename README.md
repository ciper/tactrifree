Tactrifree is a replacement driver for the Openport 2.0 that provides 32/64 bit J2534 interfaces and enables ECUFlash to function through a custom dll. This was tested on Windows 10/11 and no security settings have to be disabled. 

For Windows 7/8 use https://github.com/ciper/tactrifree-78

A copy of ecuflash_1444870_win.exe can be found here https://drive.google.com/file/d/11rm2t4Nmlz0wD0WsUBhuyRLvZcSukvC8/view
